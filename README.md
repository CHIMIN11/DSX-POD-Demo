# DSX POD Demo

Live: https://chimin11.github.io/DSX-POD-Demo/

Vera Rubin DSX POD 3D walkthrough in 7 chapters: uncabled NVL72 rack, rack line-up and cabling, container integration, sealing, dry coolers, 800 VDC power center, and campus scale-out. English by default, with a 中文 toggle.

Built with three.js r128 (loaded from CDN). No build step — open `index.html` or serve the folder with GitHub Pages.

Figures are taken from the GTC keynote and NVIDIA's press release of 2026-10-21. The 3D scene is a conceptual illustration.
